# Trust Chain — Web Dashboard

AI-Driven Consumer Complaint Intelligence for E-commerce Platforms.
Built with **Next.js 14 + TypeScript + Tailwind CSS**.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the dev server
npm run dev

# 3. Open http://localhost:3000
```

## Pages

| Route          | Description                                                       |
|----------------|-------------------------------------------------------------------|
| `/`            | Population dashboard — analytics over 20K reviews                |
| `/analyze`     | Live single-review scoring with verdict, band and components     |
| `/cases`       | Priority-sorted case queue with expandable details               |
| `/signals`     | Reference tables: features, verdict cascade, priority bands      |
| `/compare`     | Side-by-side case comparison with diff summary                   |
| `/network`     | Reviewer-business interaction graph with hover highlights         |
| `/insights`    | SHAP importance, ROC/PR curves, training history, error analysis  |
| `/about`       | Methodology, pipeline stages, limitations, reproducibility        |

## Data

All dashboard data lives in `public/data/*.json`. These files are generated by
the companion notebook `Trust_Chain_NLP.ipynb` (Section 30 — Exporting
Artefacts). The website reads them at build time, so **no Python runtime is
needed at serving time**.

To regenerate the data, run the notebook in Google Colab or locally and copy
the files from `/content/trust_chain_web_data/` into `public/data/`.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel auto-detects Next.js — no configuration needed.
4. Click **Deploy**.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 3 with warm-cream custom palette
- **Charts**: Recharts
- **Icons**: Lucide React
- **Fonts**: Inter + Playfair Display (via next/font)
